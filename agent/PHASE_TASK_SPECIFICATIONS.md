## Universal task Definition of Done

Every task must leave the repository buildable, tested and documented. Relevant security, authorization, tenant, concurrency, migration, accessibility, localization, responsive and runtime checks must pass. Evidence must be recorded before a task is marked DONE.

## Universal phase gate

All five tasks in the phase must be DONE, all acceptance criteria must pass, regression validation must pass, documentation must be synchronized, and no critical security/financial/booking/tenant defect may remain before advancement.
