# Data-Dense UX

Dense does not mean cluttered. Optimize for fast comprehension and safe action.

## Rules
- Start from the decisions the user must make.
- Make primary KPIs and exceptions visually dominant.
- Prefer meaningful grouping over decorative cards.
- Tables need sorting/filtering where useful, stable columns, empty/loading/error states, and responsive strategy.
- Calendar/scheduler views must expose conflicts, availability, holds, maintenance, and operational blocks clearly.
- Charts need explanatory labels, units, date ranges, and accessible summaries.
- Avoid chart spam; every visualization must answer a business question.
- Support progressive disclosure for secondary details.

## Car-rental examples
Owner dashboard should answer quickly:
- Which vehicles are unavailable and why?
- What pickups/returns require action today?
- What money is outstanding?
- Which documents are expiring?
- Which vehicles are underperforming?

Use exception-first design rather than a dashboard full of decorative metrics.
