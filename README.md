# Car Rental Platform

A production-grade, multi-tenant car-rental operating platform for agencies, owners, staff, and customers.

## Product surfaces

- Customer Web
- Customer Mobile App (iOS + Android)
- Owner/Admin Web
- Staff operational mobile workflows
- Shared backend API and domain services

## Core domains

Booking, availability, pricing, fleet, customers, contracts, inspections, damage, maintenance, payments, billing, notifications, partners, analytics, and AI-assisted operations.

## Documentation map

- `replit.md` — persistent Replit Agent context and non-negotiable project rules
- `AGENTS.md` — coding and agent operating rules
- `docs/` — product requirements, workflows, business rules, and feature specifications
- `architecture/` — technical architecture and architecture decision records
- `references/` — audited open-source references and extracted patterns
- `research/` — market, competitor, UX, and Algeria-specific research
- `agent/` — phased implementation plan, prompts, and verification checklists

## Development principle

Plan first, implement in small verifiable phases, preserve documented business rules, test critical workflows, and update documentation whenever a decision changes.
