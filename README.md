# Kavriqo

**Car Rental & Mobility Platform**

A production-grade, multi-tenant platform combining a customer marketplace with a complete operating system for car-rental agencies.

## Product surfaces

- **Kavriqo Marketplace** — customer web discovery, map/list search, agency profiles, availability, booking, reviews and support.
- **Kavriqo for Agencies** — agency owner/admin operating suite for fleet, bookings, pricing, customers, contracts, inspections, damage, maintenance and finance.
- **Kavriqo Agency App** — Agency Operations Mobile App for pickup, return, QR, inspection, photos and operational workflows.
- **Kavriqo Platform** — private platform control center for agencies, verification, plans, trials, subscriptions, licenses, entitlements, advertising, commissions and platform operations.

## Core domains

Booking, availability, pricing, fleet, customers, contracts, inspections, damage, maintenance, payments, billing, notifications, marketplace discovery, agency profiles, reviews, messaging, SaaS monetization, auditability and platform administration.

## Release 1

- Customer responsive Web marketplace
- Agency Owner/Admin Web
- Agency Operations Mobile App
- Platform Owner Web
- Shared NestJS backend
- PostgreSQL + PostGIS + Prisma
- Arabic/French/English + RTL
- DZD-first regional configuration

Customer Mobile App, advanced AI, telematics/GPS, loyalty, advanced partner ecosystem and advanced online payment integrations are planned for later phases.

## Brand

**KAVRIQO**

Descriptor: **Car Rental & Mobility Platform**

The K symbol/wordmark should be implemented consistently across the web, favicon and future app icon. Visual identity must remain professional, accessible and useful in Arabic, French and English.

## Development principle

Plan first, implement in verified phases, preserve documented business rules, test critical workflows, record executable evidence, and keep the repository documentation synchronized with the implementation.

## Reference projects

The repository contains audited rental, fleet-management, business-application, design, testing and agent-skill references. They are used for patterns and ideas, not for blind code or branding reuse.
